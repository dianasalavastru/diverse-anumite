# Design Inspiration

## Primary Inspiration

The primary inspiration for the overall website experience is:

https://www.septiembrearquitectura.com/

The goal is NOT to copy the visual design.

The goal is to learn from the interaction model, pacing and storytelling.

## Inspiration Principles

The website should feel:

- editorial
- calm
- premium
- image-first
- typography-driven
- highly curated
- timeless

The user should discover the content progressively while scrolling.

Scrolling is part of the storytelling.

## What we want to borrow

### Homepage flow

We like the way the homepage unfolds gradually instead of presenting everything immediately.

### Scroll rhythm

Large visual sections.

Breathing space.

Long pauses.

No visual overload.

### Typography

Oversized typography.

Minimal text.

Strong hierarchy.

### Photography

Large imagery.

Images tell the story.

Text supports the images.

### Motion

Subtle.

Elegant.

Slow.

Smooth.

Never distracting.

Motion should reinforce the editorial feeling.

### Navigation

Minimal.

Always available.

Never dominant.

### White space

Generous spacing.

Comfortable reading rhythm.

No dense layouts.

## What we DO NOT want to copy

We are not recreating Septiembre.

We are creating a unique identity.

Specifically:

- different branding
- different layout
- different color system
- different project presentation
- different content hierarchy
- different interactions where appropriate

## Our differentiators

Unlike Septiembre, this website must also communicate technical expertise.

Additional services include:

- 3D laser scanning
- drone photogrammetry
- point cloud documentation
- digital surveying

The portfolio should naturally integrate these services without breaking the editorial feeling.

The homepage should remain portfolio-first rather than service-first.
